# MungChi# 뭉치 난투

피코파크 느낌의 협동 + 경쟁 브라우저 파티 게임입니다. 최대 8명이 4자리 방 코드로 모여서 할 수 있어요.

## 플레이 방법
1. `index.html`을 GitHub Pages에 올려요. 저장소 Settings → Pages → Branch: `main` / root를 고르면 돼요.
2. 방장이 **방 만들기**를 누르면 4자리 코드가 나와요. 친구들은 그 코드를 입력하고 **참가하기**를 눌러요.
3. 로비에서 할 수 있는 것: 준비하기, 캐릭터 편집, 팀 편성, 모드 고르기·투표, 맵 테마 고르기. 모두 준비되면 방장이 시작해요.

## 모드
- 🤝 **협동**
  - 열쇠 대작전: 상자를 밀고, 서로 밟고 올라서고, 무거운 블록은 여러 명이 같이 밀어요.
  - 한 줄 운명: 모두 밧줄로 묶여 있고, 한 명이 떨어지면 다 같이 체크포인트로 돌아가요.
- ⚔️ **경쟁**
  - 왕관 쟁탈: 왕관을 오래 쓰고 있는 사람이 이겨요.
  - 우주선 피구: 우주선을 타고 공을 던져 상대를 맞혀요.
- 🔥 **혼합**
  - 배신의 탑: 협동해서 올라가지만 코인은 각자 챙기고, 꼭대기 보물상자는 한 명만 열 수 있어요.
  - 팀 공 넣기: 레드팀과 블루팀이 맞붙는 축구예요.

## 기술 메모
- HTML 파일 하나로 되어 있고, 빌드 과정이 없어요.
- 네트워크는 [PeerJS](https://peerjs.com) 무료 클라우드 서버로 접속을 연결하고, 실제 게임 데이터는 WebRTC P2P로 주고받아요.
- 방장 브라우저가 물리 계산을 전부 맡고, 다른 사람들은 입력만 보내요. 방장은 초당 30번 상태를 보내요.
- TURN 서버를 따로 설정하지 않았기 때문에, 일부 회사망이나 모바일 데이터 환경에서는 접속이 안 될 수 있어요. 그럴 땐 `new Peer(...)` 옵션의 `config.iceServers`에 TURN 서버를 추가하면 돼요.
- 프로필(닉네임, 색상, 캐릭터, 사진)은 브라우저 localStorage에 저장돼요. 사진은 96×96 크기로 줄여서 보내요.
